# Web Introduktion

## Introduktion

I webbutveckling ska ni lära er hur man skapar egna statiska hemsidor.
Det betyder att ni ska bygga sidor från grunden upp som fungerar på både dator och telefon.

När vi gör hemsidor använder vi två språk: HTML och CSS.

## HTML

HTML (*HyperText Markup Language*) är ett språk som vi använder för att strukturera innehållet på en hemsida. HTML är ett märkspråk, vilket betyder att vi skriver taggar eller element för att beskriva olika delar av sidan.

En vanlig tag ser ut så här:

```html
<p>Hej!</p>
```

Taggar är oftast uppbyggda med en starttag, innehåll och en sluttag. `<p>` används för att skapa ett stycke text.

## CSS

CSS (*Cascading Style Sheets*) är ett språk som vi använder för att styla hemsidan. CSS kan ändra saker som typsnitt, färger, textstorlek och placering av element.

```css
p {
    font-size: large;
    color: red;
}
```

Den här koden gör att alla `<p>`-taggar får större text och blir röda.

## Sammanfattning

- HTML beskriver innehållet på sidan.
- CSS beskriver hur sidan ser ut.
- Tillsammans bygger de en hemsida.
